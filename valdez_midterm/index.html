Animation Description

For the TDreads animation, I took a PNG of the character “Golden Freddy” and gave it a flickering effect. With this animation, I took inspiration from the secret ending of “Ultimate Custom Night”, so I made the background completely black and put Golden Freddy in the center. In my CSS, I made sure the animation's duration was 1.7 seconds, so it’s constantly flickering, while also having the iteration count be infinite, so it doesn’t stop. While looking for ways to make my animation better, I found a way to make a glow effect using the drop-shadow property. For the ThatPunchKid animation, I took a rat PNG and made it spin in circles. I used the linear property in my CSS to make it spin at the same speed from beginning to end. I used the color green for the background because it is ThatPunchKid’s favorite color. I made the rat spin by using keyframes to rotate it from 0 degrees to 360 degrees. For the FusionZGamer animation, I took a pirate hook because his profile picture is of a pirate fox character from “Five Nights at Freddy’s”, and made it move back and forth. I made the background for this one purple since it matches his profile picture. I used an ease-in-out property to make sure the hook moves slowly from beginning to end.
